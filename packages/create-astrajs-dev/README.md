# create-astrajs.dev

Scaffold a new AstraJS project:

```bash
npm create astrajs.dev@latest my-app -- --template minimal
```

Options: `--template minimal|frontend|fullstack` (default: fullstack) and `--yes` to skip prompts.

Delegates to the [`astrajs.dev`](https://www.npmjs.com/package/astrajs.dev) CLI.
